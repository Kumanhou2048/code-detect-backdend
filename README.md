> 成员：陈兆亮 陈誉文 古文浩 黄伟业 何智宇

## 项目简介

本项目将开发一个基于大模型的代码检查与优化建议工具，能够自动分析软件项目的代码，识别潜在问题，并生成具体的优化和重构建议。
工具可以支持多种编程语言（如Python、Java、C++等），并提供详细的优化报告，帮助开发者快速改进代码质量。

## 核心功能

1.本项目将开发一个基于大模型的代码检查与优化建议工具，能够自动分析软件项目的代码，识别潜在问题，
并生成具体的优化和重构建议。工具可以支持多种编程语言（如Python、Java、C++等），并提供详细的优化报告，帮助开发者快速改进代码质量。

2.优化建议生成  
基于大模型生成具体的优化建议，例如：
改进变量、函数、类的命名。
优化算法和数据结构以提升运行效率。
重构代码结构以提高可读性和可维护性。

3.优化报告生成  
生成详细的优化报告，包括问题描述、优化建议和修改示例。 
提供可视化展示，帮助开发者快速理解问题和改进方案。
